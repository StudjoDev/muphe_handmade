## 一、建立 Google Form

### 步驟 1：建立新表單

1. 前往 [Google Forms](https://forms.google.com/)
2. 點選 **「+」空白表單** 或使用範本庫
3. 在表單標題處輸入：**水晶能量諮詢單**
4. 在表單描述處輸入：

```
歡迎來到水晶能量諮詢！✨
請填寫以下資訊，我們將為您量身推薦最適合的水晶能量搭配。
所有資訊僅供諮詢使用，我們將嚴格保密。
```

## 二、設定表單欄位

請依照以下順序建立各個欄位：

### 欄位 1：客人姓名

| 項目     | 設定值              |
|----------|--------------------|
| 問題類型 | **簡答**（短文字回答）|
| 問題文字 | 客人姓名             |
| 必填     | ✅ 是               |
| 說明     | （不需要）           |

**操作步驟：**
1. 點選第一個問題區塊
2. 將問題類型設為 **「簡答」**
3. 輸入問題文字：`客人姓名`
4. 開啟右下角的 **「必填」** 開關

## 三、連結 Google Sheets

將 Google Form 的回應連結至現有的「水晶諮詢資料庫」Google Sheets。

### 方法 A：連結至現有試算表（推薦）

1. 在 Google Form 編輯頁面中，點選上方的 **「回覆」** 分頁
2. 點選右上角的 **「連結至試算表」** 圖示（綠色 Sheets 圖示）
3. 選擇 **「選取現有的試算表」**
4. 在彈出視窗中找到並選擇 **「水晶諮詢資料庫」**
5. 點選 **「選取」**
6. 表單回應會自動建立一個新的工作表（預設名稱為「表單回應 1」）

> ⚠️ **注意**：此方法會在現有的試算表中建立一個 **新的工作表分頁**（而非寫入現有的「諮詢紀錄」分頁）。如果您希望資料寫入「諮詢紀錄」分頁，建議使用方法 B。

### 方法 B：透過 Apps Script 處理（進階）

如果您希望表單回應直接寫入已有的「諮詢紀錄」工作表，可以透過 Apps Script 的 `onFormSubmit` 觸發器來實現：

1. 在 Google Form 中，將回覆連結至試算表（使用方法 A）
2. 在 Apps Script 中建立 `onFormSubmit` 函式，將資料從「表單回應 1」分頁轉移至「諮詢紀錄」分頁
3. 或者，直接在 Apps Script 中監聽表單提交事件，手動寫入資料

## 四、設定 Apps Script 觸發器

### 步驟 1：開啟 Apps Script

1. 在 Google Sheets **「水晶諮詢資料庫」** 中
2. 點選上方選單 **「擴充功能」** → **「Apps Script」**
3. 進入 Apps Script 編輯器

### 步驟 2：確認 onFormSubmit 函式存在

在您的 `Code.gs`（或相關檔案）中，確認已有處理表單提交的函式：

```javascript
/**
 * Google Form 提交時的觸發函式
 * @param {Object} e - 表單提交事件物件
 */
function onFormSubmit(e) {
  try {
    const sheet = SpreadsheetApp.getActiveSpreadsheet()
      .getSheetByName('諮詢紀錄');
    
    // 取得表單回應
    const responses = e.namedValues;
    
    // 時間戳記
    const timestamp = new Date();
    
    // 取得各欄位值
    const name = responses['客人姓名'] ? responses['客人姓名'][0] : '';
    const contact = responses['聯絡方式'] ? responses['聯絡方式'][0] : '';
    const gender = responses['性別'] ? responses['性別'][0] : '';
    const wearHabit = '手鍊/手環';
    const wristSize = responses['淨手圍'] ? responses['淨手圍'][0] : '';
    const colorPref = responses['偏好色系'] ? responses['偏好色系'].join(', ') : '';
    const goals = responses['期望目標'] ? responses['期望目標'].join(', ') : '';
    const description = responses['狀態描述'] ? responses['狀態描述'][0] : '';
    const budget = responses['預算範圍'] ? responses['預算範圍'][0] : '';
    
    // 寫入「諮詢紀錄」工作表
    sheet.appendRow([
      timestamp,       // 時間戳記
      name,            // 客人姓名
      contact,         // 聯絡方式
      gender,          // 性別
      wearHabit,       // 配戴習慣
      wristSize,       // 淨手圍
      colorPref,       // 偏好色系
      goals,           // 期望目標
      description,     // 狀態描述
      budget,          // 預算範圍
      '',              // AI初步推薦（稍後由 AI 填入）
      '待處理',        // 處理狀態
      ''               // 備註紀錄
    ]);
    
    // 取得剛寫入的列號
    const lastRow = sheet.getLastRow();
    
    // 呼叫 AI 推薦函式（如果存在）
    if (typeof generateRecommendation === 'function') {
      generateRecommendation(lastRow);
    }
    
    // 發送 LINE 通知（如果存在）
    if (typeof sendLineNotification === 'function') {
      sendLineNotification(lastRow);
    }
    
    Logger.log('表單回應已成功處理，寫入第 ' + lastRow + ' 列');
    
  } catch (error) {
    Logger.log('onFormSubmit 錯誤：' + error.toString());
  }
}
```

### 步驟 3：設定觸發器

1. 在 Apps Script 編輯器中，點選左側的 **「觸發條件」** 圖示（⏰ 時鐘圖示）
2. 點選右下角的 **「+ 新增觸發條件」**
3. 設定觸發器：

| 項目                   | 設定值                   |
|------------------------|-------------------------|
| 選擇要執行的函式         | `onFormSubmit`           |
| 選擇要執行的部署作業     | `Head`                   |
| 選擇活動來源            | **從試算表**              |
| 選擇活動類型            | **提交表單時**            |
| 失敗通知設定            | 依需求設定（建議「每天」）  |

4. 點選 **「儲存」**
5. 系統可能會要求您授權，請點選 **「允許」**

> ⚠️ **授權注意事項**：如果出現「這個應用程式未經 Google 驗證」的警告，請點選 **「進階」** → **「前往（不安全）」** → **「允許」**。這是因為 Apps Script 專案尚未通過 Google 驗證，但對自己的專案是安全的。

### 步驟 4：測試觸發器

1. 開啟 Google Form 的預覽（點選右上角的 👁️ 眼睛圖示）
2. 填寫一筆測試資料並提交
3. 回到 Google Sheets 確認：
   - 「諮詢紀錄」工作表中是否有新增一列
   - 各欄位資料是否正確對應
   - AI 推薦是否有自動填入
   - LINE 通知是否已收到

## 五、表單外觀設定

### 主題與配色

1. 在 Google Form 編輯頁面中，點選上方的 **「自訂主題」** 圖示（🎨 調色盤）
2. 建議設定：

| 項目       | 建議值                       |
|-----------|------------------------------|
| 標題字型   | 選擇優雅風格                   |
| 主題顏色   | 紫色系（#7B1FA2 或 #9C27B0）  |
| 背景色     | 淺色背景                      |
| 頁首圖片   | 上傳水晶相關的橫幅圖片          |

### 設定選項

1. 點選右上角的 **「⚙️ 設定」**
2. 建議設定：

| 分頁     | 項目               | 建議設定                   |
|---------|--------------------|--------------------------  |
| 回覆     | 收集電子郵件地址     | 關閉（不強制登入 Google）    |
| 回覆     | 限制為一次回覆       | 關閉（允許多次填寫）         |
| 回覆     | 允許編輯回覆         | 關閉                       |
| 簡報     | 顯示進度列           | 關閉（單頁表單不需要）       |
| 簡報     | 確認訊息             | 感謝您的填寫！我們將盡快為您準備專屬的水晶能量推薦 ✨ |

## 六、測試與驗證

### 測試清單

- [ ] 表單可正常開啟和提交
- [ ] 必填欄位有驗證提示
- [ ] 所有選項可正常選取
- [ ] 多選（核取方塊）可複選
- [ ] 提交後顯示確認訊息
- [ ] Google Sheets 「諮詢紀錄」中出現新資料
- [ ] 各欄位對應正確
- [ ] AI 推薦自動生成（如已設定）
- [ ] LINE 通知已收到（如已設定）

### 取得表單連結

1. 點選 Google Form 右上角的 **「傳送」** 按鈕
2. 點選 **連結** 圖示（🔗）
3. 勾選 **「縮短網址」**
4. 複製連結
5. 此連結可用於 LINE 圖文選單的「填寫諮詢單」按鈕
